# Kura

Finanzas personales y de negocio, juntas, para gente que gana plata por muchos lados.
Kenzō, su administrador de confianza, reparte cada ingreso en cofres, le dice cuánto
necesita hacerse hoy y responde «¿puedo pagar esto?» con plata segura.

- **Cofres:** pagos fijos, negocio, colchón y libre.
- **Meta del día:** según pagos fijos, días de descanso y cuánto se hace por hora.
- **Kenzō sin IA:** entiende frases comunes con reglas; las cuentas siempre las hace el código.
- **Kenzō con IA (opcional):** Qwen 3.5 (0.8B o 2B) corriendo dentro del celular con LiteRT-LM,
  elegido según la RAM y descargado solo por wifi. Nada sale del teléfono.

La APK se compila sola con GitHub Actions en cada cambio a `main` (ver *Releases*).
